# Heli Beauty Studio — سالن زیبایی هلیا

سیستم مدیریت سالن زیبایی (مشتریان، خدمات، کارمندان، فیش حقوقی، انبار، هزینه‌ها، سود و زیان).
برنامه‌ای با پایتون (Flask) که هم به صورت **اپلیکیشن دسکتاپ** (ویندوز/مک) و هم به صورت **وب‌اپ** (روی سرور) قابل اجراست.

---

## ۱. ورود به سیستم
سیستم لاگین فعال است.
- کاربر پیش‌فرض مدیر: **`admin`** / رمز: **`admin123`**
- (اولین بار بعد از اجرا، از منوی «کاربران» رمز را تغییر دهید.)

---

## ۲. اجرا به صورت اپلیکیشن (ویندوز / مک)

### روش الف — دانلود فایل آماده (نیاز به پایتون ندارد)
۱. بروید به گیت‌هاب پروژه → تب **Actions**
۲. روی **Build Windows EXE** (یا **Build macOS App**) کلیک کنید → **Run workflow**
۳. بعد از اتمام (~۳ دقیقه)، از بخش **Artifacts** فایل را دانلود کنید:
   - ویندوز: `HeliBeautyStudio.exe`
   - مک: `HeliBeautyStudio`
۴. فایل را اجرا کنید → مرورگر به طور خودکار باز می‌شود (`http://localhost:5000`).
۵. برای بستن، پنجره ترمینال را ببندید.

### روش ب — ساخت محلی (اگر پایتون دارید)
```bash
pip install -r requirements.txt pyinstaller
python build.py
# خروجی: dist/HeliBeautyStudio.exe  (ویندوز) یا  dist/HeliBeautyStudio  (مک)
```

### روش ج — اجرای مستقیم (بدون بسته‌بندی)
```bash
pip install -r requirements.txt
python run.py
```

## ۳. محل ذخیره داده‌ها (مهم برای بکاپ و انتقال)

همه داده‌ها در پوشه **`data/`** کنار فایل اجرایی ذخیره می‌شوند:
- `employees.xlsx` — کارمندان
- `customers.xlsx` — مشتریان
- `transactions.xlsx` — تراکنش‌ها / خدمات
- `inventory.xlsx` — انبار
- `expenses.xlsx` — هزینه‌ها
- `employee_deductions.xlsx` — کسورات متغیر
- `users.db` — کاربران و دسترسی‌ها

## ۴. بکاپ‌گیری

### الف) از داخل برنامه
منوی **«بکاپ»** →
- **روزانه / هفتگی / ماهانه / کامل**: خروجی اکسل از تراکنش‌ها
- **دانلود ZIP (برای انتقال به سرور)**: کل پوشه `data/` را در یک فایل ZIP دانلود می‌کند (بهترین روش برای نگهداری و جابجایی همه داده‌ها)

### ب) بکاپ خودکار روزانه
اسکریپت `backup.py` هر روز یک نسخه ZIP از پوشه `data/` می‌گیرد و در `backups/` می‌ریزد (۳۰ نسخه آخر نگه داری می‌شود).

تنظیم زمان‌بندی:
- **ویندوز**: Task Scheduler → اجرای `python backup.py` روزانه
- **مک / لینوکس**: در crontab بنویسید:
  ```bash
  0 3 * * * cd /path/to/app && python backup.py
  ```

اجرای دستی:
```bash
python backup.py
```

## ۵. انتقال به سرور (تبدیل به وب‌اپ با دسترسی از هر جا)

وقتی سرور (VPS) گرفتید:
۱. کد را روی سرور کلون کنید:
   ```bash
   git clone https://github.com/pelakee13/salon-accounting.git
   cd salon-accounting
   pip install -r requirements.txt
   ```
۲. پوشه **`data/`** را که روی کامپیوتر/مک پر کرده‌اید کپی کنید روی سرور (در همان مسیر).
   → تمام داده‌ها دقیقاً همان‌طور منتقل می‌شوند؛ چیزی گم نمی‌شود.
۳. اجرا با Gunicorn + Nginx:
   ```bash
   pip install gunicorn
   gunicorn -w 4 -b 127.0.0.1:5000 web_app:app
   ```
   (تنظیمات کامل Nginx + HTTPS در مستندات نصب سرور آورده شود.)

## ۶. ساختار پروژه
```
web_app.py            برنامه اصلی Flask
auth.py               احراز هویت و سطوح دسترسی
run.py                launcher (باز کردن مرورگر + اجرای سرور)
build.py              ساخت EXE/اپلیکیشن با PyInstaller
backup.py             بکاپ خودکار روزانه
templates/            صفحات HTML
static/               فایل‌های ایستا (CSS و غیره)
data/                 داده‌های کسب‌وکار (در زمان اجرا ساخته می‌شود)
requirements.txt      پکیج‌های پایتون
.github/workflows/    ساخت خودکار EXE (ویندوز) و اپلیکیشن (مک)
```

## ۷. سطوح دسترسی
- **admin**: دسترسی کامل
- **reception** (پذیرش): داشبورد، ثبت خدمات، مشتریان، گزارش‌ها
- **employee** (کارمند): داشبورد، گزارش‌ها، فیش حقوقی

از منوی «کاربران» مدیران جدید با نقش دلخواه بسازید.
