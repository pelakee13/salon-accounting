# 💇‍♀️ هلیا بیوتی

نرم‌افزار حسابداری ساده و زیبا برای سالن آرایش هلیا بیوتی با رابط کاربری فارسی (RTL) و فونت زیبای وزیرمتن.

## ✨ امکانات

- 💰 **ثبت تراکنش** — افزودن خدمات با نام مشتری، کارمند و مبلغ
- 📊 **گزارش امروز** — خلاصه درآمد، تعداد مشتری و پورسانت کارمندان
- 📅 **گزارش ماهانه** — تفکیک درآمد و پورسانت بر اساس کارمند و دسته خدمت
- 📒 **دفترچه مشتریان** — مدیریت مشتریان با جستجو و خروجی اکسل
- 👥 **مدیریت کارمندان** — افزودن/ویرایش/حذف با درصد پورسانت
- 🛎️ **مدیریت خدمات** — لیست خدمات با قیمت پیش‌فرض
- 📦 **بکاپ** — خروجی اکسل روزانه/هفتگی/ماهانه/کامل/دلخواه

## 🚀 اجرا

### روش ۱: وب‌اپ (پیشنهادی — کار میکنه روی هر دستگاه)

```bash
# نصب پیش‌نیاز
pip install flask openpyxl

# اجرای وب‌اپ
python web_app.py
```

بعد مرورگر را باز کنید: **http://localhost:5000**

> 💡 از موبایل هم می‌توانید استفاده کنید! کافیه IP سرور رو باز کنید.

### روش ۲: فایل اجرایی ویندوز (.exe)

```bash
# نصب پیش‌نیاز (روی ویندوز)
pip install pyinstaller openpyxl

# ساخت فایل اجرایی
bash build_exe.sh
# یا مستقیم:
pyinstaller --onefile --windowed --name "حسابداری_سالن" salon_app.py
```

خروجی: فایل `dist/حسابداری_سالن.exe`

> ⚠️ فایل `.exe` فقط روی ویندوز کار می‌کنه. برای موبایل از وب‌اپ استفاده کنید.

### روش ۳: اجرا با پایتون (نیاز به نصب پایتون)

```bash
pip install openpyxl
python salon_app.py
```

## 📁 ساختار فایل‌ها

```
salon-accounting/
├── salon_app.py          # اپ اصلی (tkinter - دسکتاپ)
├── web_app.py            # وب‌اپ (Flask - مرورگر)
├── build_exe.sh          # اسکریپت ساخت .exe
├── templates/            # تمپلیت‌های HTML
│   ├── base.html
│   ├── index.html
│   ├── reports.html
│   ├── monthly.html
│   ├── customers.html
│   ├── employees.html
│   ├── services.html
│   └── backup.html
├── data/                 # فایل‌های اطلاعات (خودکار ساخته می‌شود)
│   ├── employees.xlsx
│   ├── services.xlsx
│   ├── transactions.xlsx
│   └── customers.xlsx

```

## 💡 نکات

- فایل‌های اکسل در پوشه `data/` ذخیره می‌شوند
- در اولین اجرا، کارمندان و خدمات پیش‌فرض به صورت خودکار اضافه می‌شوند
- بکاپ‌ها به صورت اکسل چندشیت (تراکنش + خلاصه کارمندان + لیست کارمندان) ذخیره می‌شوند
- تاریخ‌ها به صورت شمسی نمایش داده می‌شوند

## 📱 دسترسی از موبایل (وب‌اپ)

1. وب‌اپ رو روی کامپیوتر اجرا کنید
2. IP کامپیوتر رو پیدا کنید (مثلاً `192.168.1.100`)
3. در موبایل مرورگر باز کنید: `http://192.168.1.100:5000`
4. همین! 🎉
