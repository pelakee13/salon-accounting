# آکادمی هلیا — سیستم مدیریت سالن زیبایی

سیستم مدیریت حسابداری و عملیاتی سالن زیبایی با Flask.
شامل مدیریت مشتریان، خدمات، کارمندان، هزینه‌ها، انبار، فاکتور PDF و داشبورد.

## ویژگی‌ها

- **احراز هویت و نقش‌ها**: admin (مدیر کل)، reception (پذیرش)، employee (کارمند)
- **صفحه ثبت خدمات**: جستجوی زنده مشتری، روش‌های پرداخت متعدد، تخفیف، امتیاز
- **فاکتور PDF**: RTL، فونت فارسی (وزیرمتن)، بدون ستون کمیسیون (طبق تنظیمات سالن)
- **گزارش‌ها**: روزانه، ماهانه، سود و زیان، مقایسه ماه جاری با ماه قبل
- **انبار**: ورود/خروج، تاریخچه، هشدار کم‌موجودی، کسر خودکار هنگام ثبت خدمت
- **هزینه‌ها**: دسته‌بندی (اجاره، حقوق، مواد، ...) + خلاصه ماهانه
- **امنیت**:
  - تغییر رمز عبور (حداقل ۸ کاراکتر + حرف + عدد)
  - محافظت CSRF روی همه فرم‌ها
  - محدودیت نرخ (Rate-limit): ۵ تلاش ناموفق → قفل ۳۰ دقیقه‌ای
  - Session ایمن (HttpOnly + SameSite + Secure روی HTTPS)
  - دسترسی بر اساس نقش (RBAC) در سطح سرور و رابط کاربری

## نصب

```bash
# نیازمندی‌ها
pip install -r requirements.txt

# اجرا
python3 web_app.py
```

سپس مرورگر را باز کنید:
- محلی: http://127.0.0.1:5000
- یا از طریق تانل (localhost.run / ngrok و غیره)

## ورود پیش‌فرض

| نام کاربری | رمز عبور | نقش |
|-----------|---------|-----|
| admin | admin123 | مدیر کل |

> نکته امنیتی: پس از اولین ورود، از منوی «تغییر رمز» رمز مدیر را تغییر دهید.
> متن راهنمای «admin / admin123» از صفحه ورود حذف شده است.

## نقش‌ها و دسترسی‌ها

### مدیر (admin)
دسترسی کامل به همه بخش‌ها شامل: ثبت خدمات، مشتریان، داشبورد، گزارش‌ها،
ماهانه، هزینه‌ها، سود و زیان، انبار، کارمندان، خدمات، بکاپ، کاربران، تغییر رمز.

### پذیرش (reception)
فقط: ثبت خدمات، مشتریان، گزارش امروز (روزانه).
داشبورد و بقیه بخش‌ها (کاربران، بکاپ، هزینه‌ها، سود و زیان، کارمندان، خدمات، انبار، ماهانه)
برای پذیرش **مخفی و غیرقابل دسترسی** هستند.

### کارمند (employee)
فقط: داشبورد (کمیسیون‌های خودش) و گزارش خدمات خودش.
هیچ دسترسی به ثبت خدمات، مشتریان، هزینه‌ها و مدیریت ندارد.

│   ├── login.html
│   ├── change_password.html
│   ├── index.html      # ثبت خدمات
│   ├── dashboard.html
│   ├── customers.html
│   ├── expenses.html
│   ├── inventory.html
│   ├── monthly.html

    ├── transactions.xlsx
    ├── employees.xlsx

## نکات فنی

- **ذخیره‌سازی**: داده‌های کسب‌وکار در فایل‌های Excel (openpyxl)، کاربران در SQLite.
- **تاریخ**: همه تاریخ‌ها شمسی (Jalali) هستند.
- **زبان**: رابط کاربری کاملاً فارسی و RTL.
- **فاکتور PDF**: ستون کمیسیون طبق درخواست سالن حذف شده است.

## تغییر رمز عبور

از منوی کناری «تغییر رمز» استفاده کنید. رمز باید:
- حداقل ۸ کاراکتر
- شامل حداقل یک حرف و یک عدد باشد

## بکاپ

داده‌های شما در پوشه `data/` قرار دارند. برای بکاپ‌گیری کافی است این پوشه
به صورت منظم کپی شود. صفحه «بکاپ» در پنل ادمین امکان دانلود فایل‌های Excel
را فراهم می‌کند.

## عیب‌یابی

- **خطای فونت در فاکتور**: فایل `fonts/Vazirmatn.ttf` باید موجود باشد.
- **دسترسی رد شد**: اگر با نقش محدود وارد شدید و صفحه‌ای باز نشد، طبیعی است
  (مثلاً کارمند نمی‌تواند هزینه‌ها را ببیند).
- **تانل خارجی**: برای دسترسی از اینترنت، از localhost.run یا ngrok استفاده کنید.
  کد نیازی به تنظیم خاصی ندارد (فقط پورت ۵۰۰۰ را فوروارد کنید).
